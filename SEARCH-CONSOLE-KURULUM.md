# Google Search Console Kurulumu

1. search.google.com/search-console adresinde Alan adı mülkü ekleyin.
2. Verilen TXT kaydını domain DNS paneline ekleyin. GitHub Pages adresi kullanılıyorsa URL ön eki mülkü de eklenebilir.
3. Site haritaları bölümüne sitemap.xml gönderin.
4. Önce ana sayfa, mersin-uyducu.html, mersin-televizyon-tamiri.html ve mersin-kamera-sistemleri.html için URL Denetleme yapın.
5. Dizine ekleme, Core Web Vitals, Manuel İşlemler ve Güvenlik Sorunları raporlarını kontrol edin.
6. İlk 90 gün haftalık olarak sorgu, gösterim, tıklama, CTR ve ortalama konumu kaydedin.
