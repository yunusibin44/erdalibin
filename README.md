## Yayınlama (GitHub Pages)
ZIP içindeki `index.html`, diğer `.html` dosyaları, `assets/`, `sitemap.xml`, `robots.txt`, `CNAME` ve faviconları **depo köküne** yükleyin. Eski eşadlı dosyaların üzerine yazın. `.git/` klasörü ZIP'e dahil edilmez; GitHub'a dosya yüklerken gerekmez.

GitHub > Settings > Pages > Deploy from a branch > main/root. Proje zaten GitHub Pages üzerindeyse mevcut ayarları bozmayın; sadece dosyaları güncelleyin. `CNAME` dosyasını koruyun. `.htaccess` Apache için tasarlanmıştır ve GitHub Pages tarafından uygulanmaz.
