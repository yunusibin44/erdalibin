# İbin Elektronik Web Sitesi

GitHub Pages için hazırlanmış tamamen statik HTML5/CSS3/JavaScript sitesidir.

## Yayınlama
ZIP içindeki dosyaları deponun köküne yükleyin. index.html dosyası README ile aynı seviyede olmalıdır. Settings > Pages > Deploy from a branch > main / root seçin.

## Fotoğraflar
Gerçek iş fotoğrafları hazır olduğunda assets/img klasörüne WebP olarak eklenmeli; sahte iş fotoğrafı kullanılmamalıdır.

## Search Console
Doğrulama meta etiketini tüm HTML sayfalarının head bölümüne veya yalnızca index.html içine ekleyebilirsiniz. Sitemap adresi: https://yunusibin44.github.io/erdalibin/sitemap.xml
