# İbin Elektronik Web Sitesi

GitHub Pages için hazırlanmış tamamen statik HTML5/CSS3/JavaScript sitesidir.

## Yayınlama
ZIP içindeki dosyaları deponun köküne yükleyin. index.html dosyası README ile aynı seviyede olmalıdır. Settings > Pages > Deploy from a branch > main / root seçin.

## Bilgi değiştirme
Telefon: tüm dosyalarda 0535 944 76 62 ve +905359447662 ifadelerini değiştirin. Adres: Selçuklar Mahallesi, Çiftçiler Caddesi. Domain: canonical, sitemap.xml ve robots.txt içindeki https://yunusibin44.github.io/erdalibin/ adresini değiştirin.

## Fotoğraflar
Kurumsal temsili görseller `assets/images` klasöründedir ve WebP olarak optimize edilmiştir. Bunlar gerçek müşteri işi diye sunulmaz. Erdal Usta'nın gerçek çalışma fotoğrafları hazır olduğunda aynı ölçüler korunarak değiştirilebilir.

## Tasarım ve animasyonlar
Ana stil dosyası `assets/css/premium-v4.css`, etkileşim dosyası `assets/js/premium-v4.js` dosyasıdır. Kayan hizmet bandı, ana başlığın kelime animasyonu, sağ-sol bölüm girişleri ve CTA davranışları bu dosyalardadır. Hareket azaltma ayarı açık cihazlarda animasyonlar erişilebilirlik için kapanır.

## Search Console
Doğrulama meta etiketini tüm HTML sayfalarının head bölümüne veya yalnızca index.html içine ekleyebilirsiniz. Sitemap adresi: https://yunusibin44.github.io/erdalibin/sitemap.xml
